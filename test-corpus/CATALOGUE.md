# Regression test corpus

`corpus-cells.tsv` in this directory is the single declarative catalogue of the model releases the implementation is tested against and what each one depends on. Read it before interpreting any corpus result; this page is a reader's introduction, not a second copy of the catalogue.

## What is committed here

| Path | Content |
|---|---|
| `corpus-cells.tsv` | Every catalogue cell (25 real-model releases at Rune DSL 9.83.0 plus the authored `chaos` cell), its role and its declared/resolved dependency closure |
| `chaos/chaos-1.1.0/` | The authored adversarial cell: 988 Rune sources expanded from 44 seed families, their independently generated reference Java and the declared exception registers. See `docs/CHAOS-GATE.md`. |

Nothing else under `test-corpus/` is committed. The real-model cells are acquired by the reviewer at their exact pins and are ignored by Git (`cdm/`, `drr/`, `iso20022/`, `rune-fpml/`, `rune-dsl-builtins/`).

## Acquiring the real-model cells

| Project | Repository | Access |
|---|---|---|
| CDM | https://github.com/finos/common-domain-model | Public (FINOS) |
| Rune DSL builtins | https://github.com/finos/rune-dsl | Public (FINOS) |
| DRR | rosetta-models organisation | Authorised access required |
| ISO 20022 | rosetta-models organisation | Authorised access required |
| Rune FpML | rosetta-models organisation | Authorised access required |

The public one-cell walkthrough (CDM 5.38.0 at Rune DSL 9.83.0) is in `docs/CORPUS-9.83.md`, with the machine-readable lock `docs/corpus-lock.json`. Each cell lives at `test-corpus/<corpus>/<corpus>-<version>/`; the builtins at `test-corpus/rune-dsl-builtins/rune-runtime/src/main/resources/model`.

Reference Java for every cell is generated by the released compiler that the cell's own POM pins, never by this implementation:

```sh
mvn -B -ntp -pl rosetta-source -am process-sources -Dmaven.build.cache.enabled=false
```

run from the cell's root. `process-sources` covers both the `generate-sources` binding used by CDM/DRR/ISO 20022 and the `process-sources` binding used by Rune FpML. Do not pass a cell's own `settings.xml` (it selects a private mirror). For ISO 20022 do not add `-Pgenerate`, which regenerates the `.rosetta` sources from XSD.

## Dependency closures

DRR bundles CDM and ISO 20022; the catalogue records the declared pins and the resolved closure actually loaded for each DRR cell. One substitution is material and is visible in the TSV: DRR 6.34.1 declares CDM 5.37.0 and ISO 20022 1.37.0 and is compared against CDM 5.38.0 and ISO 20022 1.38.0. Resolution-only cells are loaded solely as another cell's dependency closure and are never byte-compared.

## Validation criteria

The parser must accept every `.rosetta` file of every active cell with zero errors, produce the structural information the reference parser produces, and resolve composite workspaces (DRR plus its transitive CDM/ISO closure plus builtins). `docs/TESTING.md` describes the layers that check this.
