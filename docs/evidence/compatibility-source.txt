## The guarantee, in one paragraph

rune-dsl-plus generates Java from Rune DSL models and is held to **byte-identity with the upstream
rune-dsl 9.83.0 generator** on every model release that pins that version — 25 releases of CDM,
DRR, ISO 20022 and rune-fpml, 174,141 generated files. The guarantee is **no silent wrongness,
where it is measured**: when the engine cannot justify an output it **refuses** (a named generation
error with the file and the reason) rather than emitting plausible-looking Java; when it does emit,
the file is compared to the upstream golden byte for byte, and every difference is either healed or
listed by name with its upstream-defect evidence. At the v3.1 close (PR #605) the **byte band** —
the set of generated files that differ from upstream — across the 25-cell matrix is **zero on both
generation routes**: 174,129 files identical, 0 different, 12 not emitted and waived by name; and
the five-cell **parity ring** — the five pinned cells whose digest must hold before any change
merges — reads 34,685 of 34,686. (§ 2 defines both populations.)
