JSON receipts retain measurement values. Formatting is normalised, and occurrences of the original local development-root path are replaced with `<development-root>`; the inventory records affected field counts and both original and curated file hashes. A redacted command is historical evidence, not a ready-to-run command.

The source-report extracts are verbatim selected lines with file, revision and line ranges. They support the reported historical claims but do not contain the full raw benchmark logs. The compact compatibility rows are included separately; full original console logs are not. The inspection revision identifies where records were read, not necessarily the revision at which each experiment ran. Do not invent a missing run SHA from the extraction SHA.

To independently reproduce the results, obtain the declared corpus/dependency pins and original benchmark variants, then record a new run. The public CDM walkthrough exercises a deliberately smaller population; it cannot reproduce measurements requiring the private DRR/ISO inputs by itself.
